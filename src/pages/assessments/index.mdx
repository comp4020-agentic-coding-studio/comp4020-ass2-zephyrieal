Four assessments, each one closing a block of the semester: Observe, Create,
Test, and Question + Redesign. Each builds directly on the last — the Hate
Catalogue is where you learn to see the mechanism, The Worst Interface is
where you build one, the Hostile Design Experiment is where you find out
whether it actually works, and the Redemption Project is where you turn all
of it back on something real you want to fix.
