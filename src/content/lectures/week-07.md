Bad design doesn't require a screen. A door with a handle that reads "pull"
but only opens if you push is running the exact same trick as a checkout
button that reads "confirm" while it actually upgrades your order — an
affordance that lies about what will happen. This week leaves software
entirely to make that point with objects: chairs, packaging, public
transport, signs, vending machines, road layouts, furniture, kitchen
appliances all carry the same kind of expectation, and the same kind of
betrayal, that software does.
